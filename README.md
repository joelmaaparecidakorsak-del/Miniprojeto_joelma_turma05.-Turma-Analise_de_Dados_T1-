
# Mini Projeto - Análise de Dados

## Descrição

Projeto de análise exploratória de dados utilizando uma base de dados
de varejo em formato CSV.

## Bibliotecas utilizadas

- Pandas
- NumPy
- Matplotlib
- Seaborn

## Análises realizadas

- Carregamento da base de dados
- Verificação de registros e colunas
- Análise dos tipos de dados
- Verificação de valores nulos
- Verificação de duplicatas
- Tratamento de datas
- Limpeza dos dados
- Estatísticas descritivas
- Análise por gênero
- Análise por segmento
- Análise por categoria
- Análise dos produtos mais frequentes
- Agrupamentos com groupby
- Tabelas cruzadas
- Gráficos
- Conclusões

## Período analisado

2019 a 2022
